# kubenstack

[Talos](https://www.talos.dev/) Kubernetes cluster deployed on Proxmox via Terraform.

- **3 control planes**: `192.168.3.151`, `192.168.3.152`, `192.168.3.153`
- **3 workers**: `192.168.3.155`, `192.168.3.156`, `192.168.3.157`
- **Cluster VIP / endpoint**: `https://192.168.3.150:6443`
- **CNI**: Cilium (kube-proxy disabled, L2 load balancer on the LAN)

## Prerequisites

Install both CLIs:

```bash
# Talos
brew install siderolabs/tap/talosctl
# Kubernetes
brew install kubectl
```

## 1. Using the `talosconfig`

`terraform apply` generates the `talosconfig` file at the repo root (see
[outputs.tf](outputs.tf)). It holds the CA and client certificate needed to talk
to the Talos API on the nodes.

Easiest approach: point `talosctl` at this file via the environment variable.

```bash
export TALOSCONFIG=$(pwd)/talosconfig
```

The endpoints and nodes (the control planes) are already baked into the file.
Check that everything responds:

```bash
talosctl version            # client + server version
talosctl health             # cluster health
talosctl get members        # list of Talos nodes
```

To target a specific node:

```bash
talosctl -n 192.168.3.151 dmesg          # kernel logs of a control plane
talosctl -n 192.168.3.155 services       # services of a worker
```

> Alternative: merge the file into `~/.talos/config` instead of using the env
> variable.
> ```bash
> talosctl config merge ./talosconfig
> ```

## 2. Configuring your `kubectl` client

The `kubeconfig` is **not** generated by Terraform: you pull it straight from the
cluster with `talosctl` (the `talosconfig` must be loaded, see step 1).

```bash
# Fetch the kubeconfig and merge it into ~/.kube/config
talosctl -n 192.168.3.151 kubeconfig
```

By default, the created context points at the VIP `192.168.3.150:6443`.

Verify access:

```bash
kubectl config get-contexts        # the cluster context is listed
kubectl get nodes -o wide          # all 6 nodes should be Ready
kubectl get pods -A                # Cilium and the system components are running
```

### Fetching the kubeconfig without touching `~/.kube/config`

```bash
talosctl -n 192.168.3.151kubeconfig ./kubeconfig          # write to a local file
export KUBECONFIG=$(pwd)/kubeconfig
kubectl get nodes
```

## Reminder: (re)generating the config

```bash
terraform apply        # regenerates the talosconfig at the repo root
export TALOSCONFIG=$(pwd)/talosconfig
talosctl kubeconfig    # (re)generates the kubeconfig
```
